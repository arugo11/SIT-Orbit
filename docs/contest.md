# AI Innovators Cup 2026 Mapping

## Official preliminary perspectives

公式資料に記載された次の5観点を、そのまま確認する。

1. AIの活用目的と方法の適切さ
2. プロンプト設計の工夫と具体性
3. 最終的に人が判断・修正した点
4. テーマのオリジナリティー
5. 成果物の見やすさ・伝わりやすさ

観点ごとの公式配点は公開されていないため、独自の重みや予測点は設定しない。

一般投票は別枠であり、AgentやLLMによる得票予測を行わない。

## Evidence checklist

| 観点 | 提出前に用意する証拠 |
| --- | --- |
| AI活用目的 | 開発用fixtureとAzure Responses Hosted Tool Searchの役割分担、Agent trace |
| Prompt設計 | prompt version、入力Evidence、Structured Output |
| 人の判断 | 提案の承認・変更・却下、Before/After |
| オリジナリティー | Campus EventからEvidenceまでの閉ループ |
| 伝わりやすさ | Web・Mobile画面、3分以内の一連のデモ |
